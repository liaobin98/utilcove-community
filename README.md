# UtilCove Community

English | [简体中文](README_ZH.md)

This is the public feedback and release notes repository for [UtilCove](https://utilcove.com). Browse product updates, report tool errors, suggest features, or flag wording and translation issues.

## Product updates

See [Releases](https://github.com/liaobin98/utilcove-community/releases) and the [changelog](CHANGELOG.md) for each production update. Small changes use patch versions; broader batches use minor versions.

## Submit feedback

1. [Search existing issues](https://github.com/liaobin98/utilcove-community/issues) before posting to avoid duplicates.
2. Sign in to GitHub and [create an issue](https://github.com/liaobin98/utilcove-community/issues/new/choose) using the bug report or feature request template. Wording and translation problems can use the bug report template.
3. Include the tool or page URL, reproduction steps, expected and actual results, browser and device details, and screenshots if needed.

Issues are public. Do not share passwords, keys, personal information, sensitive files, or unredacted screenshots. For privacy-related questions, contact contact@utilcove.com; do not email passwords or keys.
