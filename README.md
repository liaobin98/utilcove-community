# UtilCove Community

[UtilCove](https://utilcove.com) 的公开反馈与发布说明仓库，用于查看版本更新、报告工具故障、提出功能建议，以及反馈文案或翻译问题。

这里不包含 UtilCove 产品源码，也不接收产品代码 PR。

## 版本更新

每次正式发版的更新内容会记录在 [Releases](https://github.com/liaobin98/utilcove-community/releases) 和本仓库的更新日志中。小范围功能调整或修复使用补丁版本，批量更新使用新的次版本。

## 提交反馈

1. 先[搜索已有 Issues](https://github.com/liaobin98/utilcove-community/issues)，避免重复提交。
2. 登录 GitHub 后，[创建 Issue](https://github.com/liaobin98/utilcove-community/issues/new/choose)，选择故障报告或功能建议模板。文案和翻译问题也可以使用故障报告模板。
3. 提供工具或页面链接、复现步骤、预期与实际结果、浏览器和设备信息；必要时提供截图。

Issues 公开可见。请勿上传密码、密钥、个人信息、敏感文件或未经脱敏的截图。隐私相关问题可通过 contact@utilcove.com 联系维护者，请勿通过邮件发送密码或密钥。

## English

This is the public feedback and release notes repository for [UtilCove](https://utilcove.com). Browse product updates, report tool errors, suggest features, or flag wording and translation issues.

It does not contain UtilCove product source code or accept product code pull requests.

See [Releases](https://github.com/liaobin98/utilcove-community/releases) and this repository's changelog for each production update. Small changes use patch versions; broader batches use minor versions.

Before posting, [search existing issues](https://github.com/liaobin98/utilcove-community/issues). To [create an issue](https://github.com/liaobin98/utilcove-community/issues/new/choose), sign in to GitHub and choose the relevant template. Wording and translation problems can use the bug report template.

Include the tool or page URL, reproduction steps, expected and actual results, browser and device details, and screenshots if needed.

Issues are public. Do not share passwords, keys, personal information, sensitive files, or unredacted screenshots. For privacy-related questions, contact contact@utilcove.com; do not email passwords or keys.
